# Carbon Credit Trading System

A web-based Carbon Credit Trading System that allows companies to manage carbon emissions, trade carbon credits, monitor transactions, and maintain environmental sustainability records.

## 🚀 Live Demo

https://vijayalaxmiawale-code.github.io/Carbon_Credit_Trading_System/

## 📌 Features

### Company Module
- Company Dashboard
- Carbon Emission Management
- Carbon Credit Marketplace
- Buy and Sell Carbon Credits
- Transaction History
- Company Profile
- Notifications
- Company Search
- Leaderboard

### Admin Module
- Admin Dashboard
- Company Management
- Blocked Companies
- Fraud Monitoring
- Analytics
- Network Monitoring
- Leaderboard

### Authentication
- User Registration
- User Login
- Role-based navigation

## 🛠️ Tech Stack
